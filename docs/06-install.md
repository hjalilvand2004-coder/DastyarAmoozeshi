# ۶) راهنمای نصب و اجرا

## ۶.۱ از سورس (ویندوز / لینوکس / مک)

پیش‌نیاز: پایتون ۳.۱۰ یا جدیدتر.

```bash
git clone https://github.com/hjalilvand2004-coder/DastyarAmoozeshi.git
cd DastyarAmoozeshi
pip install -r requirements.txt
python run.py
```

- در اولین اجرا پوشه `data/` کنار پروژه ساخته می‌شود و دیتابیس با داده نمونه (غیررسمی) مقداردهی می‌شود.
- محل ذخیره داده را می‌توان با متغیر محیطی `DASTYAR_HOME` تغییر داد.

## ۶.۴ چرخه کاری پیشنهادی برای ثبت اسناد رسمی

1. **مدیر محتوا** (`content`): صفحه «مدیریت اسناد» ← «ثبت سند جدید» ← فایل PDF/Word یا متن + متادیتا (بازه اعتبار، مقطع، رشته، سال ورود) ← ثبت (پیش‌نویس).
2. **مدیر محتوا:** «ارسال برای بررسی».
3. **تأییدکننده** (`approver`): «تأیید و انتشار» — از این لحظه سند برای دانشجویانِ داخل اسکوپ قابل جست‌وجو و استناد است.
4. اصلاح آینده: «ایجاد نسخه جدید» (پیش‌نویسِ نسخه n+1) و تکرار چرخه؛ متن نسخه منتشرشده هرگز ویرایش نمی‌شود.
5. ابطال: «ملغی کردن» با ذکر دلیل؛ سند از پاسخ‌های جاری حذف و فقط با برچسب ملغی قابل مشاهده می‌شود.
6. قواعد قابل محاسبه: در «مدیریت قواعد» ثبت و فقط پس از انتشار سند منبع، توسط تأییدکننده فعال می‌شوند.
