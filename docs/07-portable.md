# ۷) نسخه پرتابل (ویندوز — بدون نیاز به پایتون)

## محتویات بسته

- **پایتون امبدد رسمی** ۳.۱۲ (۶۴بیتی) در `runtime/python` — هیچ نصب و تنظیمی لازم نیست.
- وابستگی‌های وب (FastAPI/Uvicorn و…) به‌صورت ویل win_amd64 داخل `site-packages`.
- بیلد React (`app/web_static`) — فرانت‌اند از همان سرور سرو می‌شود.
- `RUN-DastyarAmoozeshi.bat` — راه‌انداز؛ و `README-PORTABLE.txt` — راهنمای فارسی.

## اجرا

1. ZIP را Extract کنید (مسیر بدون فاصله و بدون درایو شبکه بهتر است).
2. `RUN-DastyarAmoozeshi.bat` را دابل‌کلیک کنید.
3. مرورگر خودکار روی `http://127.0.0.1:8600` باز می‌شود؛ مستندات API: `/api/docs`.
4. برای خروج، پنجره سرور (کنسول سیاه) را ببندید.

داده‌ها در پوشه `data` کنار بسته ذخیره می‌شود (`DASTYAR_HOME` روی همان پوشه ست می‌شود)؛ کپی کل پوشه = انتقال کامل برنامه.

## ورود

- ورود با رمز: حساب‌های نمایشی `admin / expert / content / approver / student` با رمز `Name@123`.
- ورود بدون رمز (نمایش SSO): صفحه ورود ← «ورود آزمایشی بدون رمز».
- SSO واقعی دانشگاه (Keycloak/OIDC): «مدیریت سیستم ← تنظیمات» ← کلیدهای `sso_oidc_*`.

## ساخت مجدد بسته

```bash
cd frontend && npm install && npm run build && cd ..
pip install -r requirements.txt
python scripts/build_portable.py     # خروجی: dist/DastyarAmoozeshi-Portable-Windows-v<ver>.zip + sha256
```

اسکریپت فقط ویل‌های رسمی win_amd64 را نصب می‌کند؛ به کامپایلر یا ابزار خارجی نیاز ندارد.

## نکته‌های امنیتی استقرار

- نسخه پرتابل برای **ارزیابی و دمو** است؛ سرور روی `127.0.0.1` گوش می‌دهد و در شبکه منتشر نمی‌شود.
- برای استقرار واقعی در دانشگاه: `D360_HOST` و `D360_SECRET_KEY` را تنظیم کنید، پشت HTTPS معکوس‌_proxy قرار دهید و حساب‌های نمایشی را حذف/غیرفعال کنید.
