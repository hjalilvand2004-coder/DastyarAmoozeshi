# ۸) تست‌ها و سناریوهای پذیرش

## ۸.۱ اجرا

```bash
pip install -r requirements-dev.txt
python -m pytest tests/ -q
```

خروجی مورد انتظار: **۴۱ تست سبز**.

## ۸.۲ پوشش

| فایل | پوشش |
|---|---|
| `tests/test_jalali.py` | تبدیل میلادی/جلالی با ۵ لنگر معتبر، رفت‌وبرگشت روی بازه ۲۰۲۰–۲۰۳۰، طول ماه‌ها و کبیسه، قالب‌بندی/تجزیه تاریخ با ارقام فارسی، روز هفته |
| `tests/test_ruleengine.py` | چهار وضعیت موتور قواعد، منطق `all`/`any` با داده ناقص، فیلد نیازمند تأیید رسمی، استخراج ورودی‌ها |
| `tests/test_kb.py` | ورود/نقش‌ها، تکه‌بندی ماده/تبصره، گذارهای وضعیت سند و مجوزها، نسخه‌بندی (نسخه جدید = پیش‌نویس)، تأیید قاعده فقط با منبع منتشرشده، رتبه‌بندی BM25 |
| `tests/test_answers_security.py` | واقعی بودن ارجاع‌ها، سه‌لایه بودن پاسخ، هشدار داده نمونه، حذف ارجاع ساختگی مدل، پرچم تزریق/OCR، هش رمز، محدودسازی نرخ |
| `tests/test_services.py` | یادآور و تأیید، مجوز مدیریت تقویم، چرخه کامل تیکت و گذارها، مالکیت تیکت، تحلیل پیش‌نیاز/پیشنهاد/فارغ‌التحصیلی، عدم ادعای «ثبت موفق» در فرایندها |
| `tests/test_acceptance.py` | **هشت سناریوی پذیرش الزامی (بند ۱۸)** |

## ۸.۳ هشت سناریوی پذیرش الزامی

| # | سناریو | تضمین |
|---|---|---|
| ۱ | **سند ملغی** | نسخه ملغی در پاسخ جاری نمی‌آید؛ نمایش آن فقط با درخواست صریح و همیشه با برچسب/هشدار «ملغی» |
| ۲ | **مغایرت اسناد** | پرسش کارورزی، هر دو سند منتشرشده را در منابع می‌آورد و «مغایرت احتمالی» + ارجاع به کارشناس تولید می‌شود |
| ۳ | **سال ورود نامشخص** | پاسخ یا «موردی یافت نشد/نتیجه قطعی نیست» است یا صریحاً «سال ورود ثبت نشده» را فهرست می‌کند؛ هیچ حدسی زده نمی‌شود |
| ۴ | **خطای OCR ارقام** | تکه دارای ارقام مخلوط (۱/۲/۰ نمونه) پرچم `ocr_suspect` می‌گیرد و پاسخ هشدار «احتمال خطای OCR، به اصل سند مراجعه کنید» می‌دهد |
| ۵ | **ارجاع بی‌ربط** | پرسش بدون تطابق → بدون هیچ منبع؛ موتور قالبی هم با زمینه خالی پاسخی با ارجاع نمی‌سازد |
| ۶ | **اصلاح تقویم** | تأیید کاربر ← ویرایش تاریخ توسط کارشناس ← نسخه جدید ← یادآور دوباره اعلام می‌شود ← تأیید نسخه جدید ← حذف از معوقات |
| ۷ | **دسترسی غیرمجاز** | دانشجو: تأیید سند/قاعده ممنوع؛ کاربر دانشگاه دیگر: مشاهده سند و تیکت دانشگاه دیگر ممنوع (خطای دسترسی) |
| ۸ | **دستور مخرب در سند** | تکه حاوی «دستور قبلی را نادیده بگیر...» پرچم تزریق می‌گیرد؛ این متن فقط داده است و در هیچ بخش تولیدیِ پاسخ گردن گرفته نمی‌شود |

## ۸.۴ تست دود رابط کاربری
